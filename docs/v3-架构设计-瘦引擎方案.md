# BPMN-Flash v3.0 架构设计 — 瘦引擎方案

> **设计日期**: 2026-05-07  
> **设计人**: 架构师 (消钱精)  
> **状态**: 🟡 设计中，待评审  
> **核心理念**: 引擎只管流转控制，业务逻辑交给外部应用

---

## 一、设计动机

### 现有架构的问题

当前 v2.x 为每种节点类型实现了独立的执行器（UserTaskExecutor、ServiceTaskExecutor、ScriptTaskExecutor 等），导致：

1. **引擎臃肿** — 8 个执行器，每个都有自己的业务逻辑假设
2. **扩展困难** — 新增节点类型必须修改引擎代码
3. **耦合严重** — 引擎硬编码了"用户任务该怎么做"、"服务任务该怎么做"
4. **测试负担** — 每个执行器都需要大量测试，当前 35 个测试失败

### 新架构核心思想

```
旧模型：引擎知道所有节点该怎么执行
新模型：引擎只知道令牌该往哪里走，节点的业务逻辑由外部应用决定
```

**类比**：引擎是铁轨系统（决定火车往哪个方向走），外部应用是每个站台的工作人员（决定在站台上做什么）。

## 二、架构总览

### 2.1 核心公式

```
F: (Definition, State, Action) → (NewState, HookEvents)
```

引擎的输入输出不变，但内部职责大幅缩减。

### 2.2 引擎职责边界

```
┌─────────────────────────────────────────────────────────────────┐
│                    引擎内部实现 ✅                               │
├─────────────────────────────────────────────────────────────────┤
│  • BPMN XML 解析 → 图结构（节点 + 边）                          │
│  • 令牌（Token）创建、移动、销毁                                │
│  • 网关逻辑（排他/并行/包含网关的分支合并）                      │
│  • SequenceFlow 条件表达式求值                                  │
│  • StartEvent → 自动推进                                       │
│  • EndEvent → 终止令牌                                         │
│  • 流程状态管理（序列化/反序列化）                               │
│  • 钩子触发                                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                    外部应用负责 🔌                               │
├─────────────────────────────────────────────────────────────────┤
│  • UserTask — 在 onNodeEnter 中调用 suspend()，等人审批后 resume │
│  • ServiceTask — 调外部 API，完成后 resume                      │
```

## 三、钩子系统设计

### 3.1 三个核心钩子

| 钩子 | 触发时机 | 用途 |
|------|---------|------|
| **onNodeEnter** | 令牌到达一个节点时 | 外部应用判断节点类型，决定是否挂起 |
| **onNodeLeave** | 节点执行完成、令牌即将离开时 | 外部应用做收尾工作 |
| **onSequenceFlow** | 令牌沿 SequenceFlow 移动时 | 外部应用获知当前走的是哪条线 |

### 3.2 钩子上下文类型

```typescript
/**
 * 节点钩子上下文
 */
interface NodeHookContext {
  /** 当前流程状态 */
  state: ProcessState;
  /** 当前令牌 */
  token: Token;
  /** 当前节点信息 */
  node: {
    id: string;
    type: string;         // 'bpmn:userTask', 'bpmn:serviceTask', etc.
    name: string;
    properties: Record<string, any>;
    incoming: string[];   // 入边 flow id 列表
    outgoing: string[];   // 出边 flow id 列表
  };
  /** 流程定义 */
  definition: ProcessDefinition;

  /**
   * 🔑 核心方法：挂起当前令牌
   * 调用后，令牌停在当前节点，引擎不再自动推进此路线
   * 外部应用需要在适当时机调用 engine.resume() 来恢复
   */
  suspend(): void;

  /**
   * 更新令牌携带的数据
   */
  setData(data: Record<string, any>): void;

  /**
   * 更新流程变量
   */
  setVariables(variables: Record<string, any>): void;
}

/**
 * SequenceFlow 钩子上下文
 */
interface FlowHookContext {
  /** 当前流程状态 */
  state: ProcessState;
  /** 当前令牌 */
  token: Token;
  /** 当前 SequenceFlow 信息 */
  flow: {
    id: string;
    sourceRef: string;     // 源节点 id
    targetRef: string;     // 目标节点 id
    name?: string;
    conditionExpression?: string | null;
  };
  /** 源节点信息 */
  sourceNode: {
    id: string;
    type: string;
    name: string;
  };
  /** 目标节点信息 */
  targetNode: {
    id: string;
    type: string;
    name: string;
  };
  /** 流程定义 */
  definition: ProcessDefinition;
}
```

### 3.3 使用方式 — 构造函数传入钩子

```typescript
import { FlowEngine, ScriptExecutorPlugin } from 'bpmn-flash';

// 脚本执行插件（可选）
const scriptPlugin: ScriptExecutorPlugin = {
  execute(state, script, cb) {
    try {
      const result = mySafeRunner(script, state.variables);
      cb(null, result);
    } catch (e) { cb(e as Error); }
  }
};

// 所有钩子在构造时一次性注入
const engine = new FlowEngine({

  // 脚本插件：有了它 scriptTask 由引擎自动执行，不走 onNodeEnter
  scriptExecutor: scriptPlugin,

  onNodeEnter: (ctx) => {
    switch (ctx.node.type) {
      case 'bpmn:userTask':
        ctx.suspend();
        notifyAssignee(ctx.node.properties.assignee, ctx.node);
        break;
      case 'bpmn:serviceTask':
        ctx.suspend();
        callExternalAPI(ctx.node.properties.serviceRef).then(result => {
          engine.resume(state, ctx.token.id, bpmnXML, result);
        });
        break;
      default:
        // 未知类型：默认自动推进
        break;
    }
  },

  onNodeLeave: (ctx) => {
    console.log(`令牌 ${ctx.token.id} 离开节点 ${ctx.node.name}`);
  },

  onSequenceFlow: (ctx) => {
    console.log(`${ctx.sourceNode.name} → [${ctx.flow.id}] → ${ctx.targetNode.name}`);
  },
});
```

## 四、令牌生命周期

### 4.1 令牌状态

```typescript
interface Token {
  id: string;
  elementId: string;          // 当前所在节点
  status: 'active' | 'suspended' | 'completed' | 'terminated';
  data: Record<string, any>;  // 令牌携带的数据
  createdAt: Date;
  suspendedAt?: Date;         // 挂起时间（新增）
}
```

### 4.2 令牌流转流程

```
                    ┌─────────────────────────────────┐
                    │         StartEvent              │
                    │    (引擎自动创建令牌)             │
                    └──────────┬──────────────────────┘
                               │
                               ▼
                    ┌──────────────────────┐
              ┌─────│  onSequenceFlow 钩子  │
              │     └──────────────────────┘
              │                │
              │                ▼
              │     ┌──────────────────────┐
              │     │   onNodeEnter 钩子    │
              │     │                      │
              │     │  外部应用是否调用      │
              │     │  suspend() ?          │
              │     └───────┬──────┬───────┘
              │             │      │
              │      没调用  │      │ 调用了
              │             │      │
              │             ▼      ▼
              │     ┌────────┐  ┌────────────┐
              │     │ 自动    │  │ 令牌挂起    │
              │     │ 推进    │  │ status =   │
              │     │        │  │ 'suspended' │
              │     └───┬────┘  └─────┬──────┘
              │         │             │
              │         │       等待外部调用
              │         │       engine.resume()
              │         │             │
              │         ▼             ▼
              │     ┌──────────────────────┐
              │     │   onNodeLeave 钩子    │
              │     └──────────┬───────────┘
              │                │
              │                ▼
              │     ┌──────────────────────┐
              │     │   下一个节点          │
              │     │   是网关？→ 引擎处理   │
              │     │   是普通节点？→ 循环   │
              │     │   是 EndEvent？→ 结束  │
              └─────│                      │
                    └──────────────────────┘
```

### 4.3 网关节点特殊处理

网关是引擎**内部处理**的，不触发 `onNodeEnter` 的 `suspend()` 能力（因为网关不需要外部业务逻辑），但仍然触发钩子让外部感知：

```typescript
// 网关节点的钩子上下文中，suspend() 是无效的（调用会被忽略并 warn）
// 但外部应用仍能在 onNodeEnter 中感知到网关被执行
engine.on('nodeEnter', (ctx) => {
  if (ctx.node.type === 'bpmn:exclusiveGateway') {
    // 可以记录日志，但 suspend() 无效
    console.log('排他网关正在执行分支判断');
  }
});
```

**引擎内部处理的节点类型：**

| 类型 | 引擎行为 | suspend() |
|------|---------|-----------|
| `bpmn:startEvent` | 自动推进 | 无效 |
| `bpmn:endEvent` | 终止令牌 | 无效 |
| `bpmn:exclusiveGateway` | 条件求值，选择分支 | 无效 |
| `bpmn:parallelGateway` | 分裂/汇聚令牌 | 无效 |
| `bpmn:inclusiveGateway` | 条件分裂/汇聚 | 无效 |
| `bpmn:eventBasedGateway` | 等待事件触发 | 无效 |
| **其他所有类型（含 scriptTask）** | 触发 onNodeEnter 钩子，等外部决定 | **有效** ✅ |

## 五、核心 API 设计

### 5.1 FlowEngine 类

```typescript
class FlowEngine {

  // ==================== 生命周期 ====================

  /**
   * 启动流程
   * 解析 BPMN，创建初始令牌，开始推进
   * 遇到需要 suspend 的节点时停下来
   */
  startProcess(
    bpmnXML: string,
    initialData?: Record<string, any>
  ): ProcessState;

  /**
   * 恢复挂起的令牌
   * 外部应用完成业务逻辑后调用，引擎继续推进
   * @param processId - 流程实例 ID
   * @param tokenId - 要恢复的令牌 ID
   * @param data - 要合并到令牌的数据（如审批结果）
   */
  resume(
    state: ProcessState,
    tokenId: string,
    data?: Record<string, any>
  ): ProcessState;

  /**
   * 终止整个流程
   */
  terminate(state: ProcessState): ProcessState;

  // ==================== 钩子注册 ====================

  /**
   * 注册钩子
   */
  on(event: 'nodeEnter', handler: (ctx: NodeHookContext) => void | Promise<void>): void;
  on(event: 'nodeLeave', handler: (ctx: NodeHookContext) => void | Promise<void>): void;
  on(event: 'sequenceFlow', handler: (ctx: FlowHookContext) => void | Promise<void>): void;
  on(event: 'processStart', handler: (ctx: ProcessHookContext) => void | Promise<void>): void;
  on(event: 'processEnd', handler: (ctx: ProcessHookContext) => void | Promise<void>): void;

  /**
   * 注销钩子
   */
  off(event: string, handler: Function): void;

  // ==================== 查询 ====================

  /**
   * 获取当前挂起的令牌列表
   * 外部应用用这个知道"哪些节点在等我处理"
   */
  getSuspendedTokens(state: ProcessState): SuspendedTokenInfo[];

  /**
   * 获取流程当前的可视化状态
   * 返回每个节点和连线的状态（用于流程图高亮）
   */
  getFlowStatus(state: ProcessState): FlowStatusInfo;

  // ==================== 插件 ====================

  /**
   * 注册插件（批量注册钩子的快捷方式）
   */
  use(plugin: FlowPlugin): void;
}
```

### 5.2 SuspendedTokenInfo

```typescript
interface SuspendedTokenInfo {
  tokenId: string;
  nodeId: string;
  nodeType: string;
  nodeName: string;
  nodeProperties: Record<string, any>;
  tokenData: Record<string, any>;
  suspendedAt: Date;
}
```

```typescript

}
```

## 六、完整使用示例

### 6.1 请假审批流程

```typescript
import { FlowEngine } from 'bpmn-flash';

const engine = new FlowEngine();

// ========== 注册钩子 ==========

engine.on('nodeEnter', async (ctx) => {
  const { node, token } = ctx;

  switch (node.type) {
    case 'bpmn:userTask':
      // 用户任务：挂起，等待审批
      ctx.suspend();

      // 通知审批人（外部系统）
      await notificationService.send({
        to: node.properties.assignee,
        title: `待审批: ${node.name}`,
        processId: ctx.state.id,
        tokenId: token.id,
        formData: token.data,
      });
      break;

    case 'bpmn:serviceTask':
      // 服务任务：调用外部 API
      ctx.suspend();

      try {
        const result = await httpClient.post(
          node.properties.serviceUrl,
          token.data
        );
        // API 调用成功，立即恢复
        engine.resume(ctx.state, token.id, { serviceResult: result });
      } catch (error) {
        // API 失败，可以重试或者标记错误
        engine.resume(ctx.state, token.id, { error: error.message });
      }
      break;

    case 'bpmn:sendTask':
      // 发送任务：发邮件，不挂起
      await emailService.send({
        to: node.properties.recipient,
        subject: node.properties.subject,
        body: interpolate(node.properties.template, token.data),
      });
      // 不调用 suspend()，引擎自动推进
      break;

    default:
      // 默认自动推进
      break;
  }
});

engine.on('sequenceFlow', (ctx) => {
  // 记录流转路径（用于审计追踪）
  auditLog.record({
    processId: ctx.state.id,
    from: ctx.sourceNode.name,
    to: ctx.targetNode.name,
    flowId: ctx.flow.id,
    condition: ctx.flow.conditionExpression,
    timestamp: new Date(),
  });
});

engine.on('processEnd', (ctx) => {
  console.log(`流程 ${ctx.state.id} 已完成`);
  // 清理资源、发通知等
});

// ========== 启动流程 ==========

const bpmnXML = fs.readFileSync('leave-request.bpmn', 'utf-8');

let state = engine.startProcess(bpmnXML, {
  applicant: '张三',
  days: 5,
  reason: '年假',
});

// 此时 state 中会有一个 suspended 的令牌停在第一个 userTask 节点
console.log(engine.getSuspendedTokens(state));
// → [{ tokenId: 'xxx', nodeType: 'bpmn:userTask', nodeName: '主管审批', ... }]

// ========== 外部审批完成后恢复 ==========

// 假设审批人在前端点击了"同意"
state = engine.resume(state, 'xxx', {
  approved: true,
  comment: '同意请假',
});

// 引擎继续推进：
//   → 走过 sequenceFlow（触发 sequenceFlow 钩子）
//   → 到达排他网关（引擎自动判断 approved === true，选择"同意"分支）
//   → 走过 sequenceFlow
//   → 到达下一个 userTask（HR 备案）→ 再次 suspend
```

## 七、与 v2.x 的对比

### 7.1 代码量对比

| 模块 | v2.x | v3.0 | 变化 |
|------|------|------|------|
| 执行器 | 8 个文件 (~1500行) | 0 个 | 🗑️ 全部删除 |
| 网关逻辑 | 分散在执行器中 | GatewayResolver (~300行) | ✅ 集中管理 |

| 核心引擎 | WorkflowEngine + ExecutionEngine + TransitionEngine | FlowEngine (~400行) | ✅ 简化合并 |
| **总计** | ~3000 行核心代码 | ~850 行 | **-72%** |

### 7.2 职责对比

| 职责 | v2.x 谁做 | v3.0 谁做 |
|------|----------|----------|
| 解析 BPMN XML | 引擎 | 引擎（不变） |

| 网关条件求值 | 引擎 | 引擎（不变） |
| 用户任务逻辑 | 引擎(UserTaskExecutor) | **外部应用** |

### 9.1 FlowEngine.ts（主引擎）

```typescript
import { BPMNParser } from '../parser/BPMNParser';
import { TokenManager } from './TokenManager';
import { GatewayResolver } from './GatewayResolver';
import { FlowTraverser } from './FlowTraverser';
import { HookManager } from '../hooks/HookManager';
import { ProcessState, Token } from '../state/ProcessState';
import { ProcessDefinition } from '../types';

export class FlowEngine {
  private tokenManager: TokenManager;
  private gatewayResolver: GatewayResolver;
  private flowTraverser: FlowTraverser;
  private hooks: HookManager;

  constructor() {
    this.tokenManager = new TokenManager();
    this.gatewayResolver = new GatewayResolver();
    this.flowTraverser = new FlowTraverser();
    this.hooks = new HookManager();
  }

  /**
   * 启动流程
   */
  async startProcess(
    bpmnXML: string,
    initialData: Record<string, any> = {}
  ): Promise<ProcessState> {
    // 1. 解析 BPMN
    const definition = BPMNParser.parse(bpmnXML);

    // 2. 创建初始状态
    let state = this.createInitialState(definition, initialData);

    // 3. 触发 processStart 钩子
    await this.hooks.emit('processStart', { state, definition });

    // 4. 在 startEvent 创建令牌
    const startElement = this.findStartEvent(definition);
    state = this.tokenManager.createToken(state, startElement.id, initialData);

    // 5. 开始推进
    state = await this.advance(state, definition);

    return state;
  }

  /**
   * 恢复挂起的令牌
   */
  async resume(
    state: ProcessState,
    tokenId: string,
    data?: Record<string, any>,
    bpmnXML?: string
  ): Promise<ProcessState> {
    // 1. 获取或重新解析定义
    const definition = bpmnXML
      ? BPMNParser.parse(bpmnXML)
      : state._definition!;

    // 2. 恢复令牌
    state = this.tokenManager.resumeToken(state, tokenId, data);

    // 3. 触发 onNodeLeave
    const token = state.tokens.find(t => t.id === tokenId)!;
    const node = definition.elements.get(token.elementId)!;
    await this.hooks.emit('nodeLeave', {
      state, token, node, definition,
      suspend: () => {}, // nodeLeave 中 suspend 无效
      setData: (d) => { token.data = { ...token.data, ...d }; },
      setVariables: (v) => { state.variables = { ...state.variables, ...v }; },
    });

    // 4. 移动到下一个节点，继续推进
    state = await this.moveToNextNodes(state, token, node, definition);
    state = await this.advance(state, definition);

    return state;
  }

  /**
   * 核心推进循环
   * 持续推进所有 active 令牌，直到全部 suspended 或流程结束
   */
  private async advance(
    state: ProcessState,
    definition: ProcessDefinition
  ): Promise<ProcessState> {
    let hasProgress = true;
    let iterations = 0;
    const MAX_ITERATIONS = 1000;

    while (hasProgress && iterations < MAX_ITERATIONS) {
      hasProgress = false;
      iterations++;

      const activeTokens = state.tokens.filter(t => t.status === 'active');
      if (activeTokens.length === 0) break;

      for (const token of activeTokens) {
        const node = definition.elements.get(token.elementId);
        if (!node) continue;

        const isGateway = this.isGatewayNode(node.type);
        const isAutoNode = this.isAutoNode(node.type); // startEvent, endEvent

        if (isAutoNode) {
          // 自动节点：引擎内部处理
          state = await this.handleAutoNode(state, token, node, definition);
          hasProgress = true;
        } else if (isGateway) {
          // 网关节点：引擎内部处理
          // 但仍触发 nodeEnter 钩子（suspend 无效）
          await this.hooks.emit('nodeEnter', {
            state, token, node, definition,
            suspend: () => { /* 网关节点忽略 suspend */ },
            setData: (d) => { token.data = { ...token.data, ...d }; },
            setVariables: (v) => { state.variables = { ...state.variables, ...v }; },
          });

          state = this.gatewayResolver.resolve(state, token, node, definition);
          hasProgress = true;
        } else {
          // 普通节点：触发 onNodeEnter 钩子
          let suspended = false;

          await this.hooks.emit('nodeEnter', {
            state, token, node, definition,
            suspend: () => {
              suspended = true;
              state = this.tokenManager.suspendToken(state, token.id);
            },
            setData: (d) => { token.data = { ...token.data, ...d }; },
            setVariables: (v) => { state.variables = { ...state.variables, ...v }; },
          });

          if (!suspended) {
            // 外部没有挂起 → 自动推进
            await this.hooks.emit('nodeLeave', {
              state, token, node, definition,
              suspend: () => {},
              setData: (d) => { token.data = { ...token.data, ...d }; },
              setVariables: (v) => { state.variables = { ...state.variables, ...v }; },
            });
            state = await this.moveToNextNodes(state, token, node, definition);
            hasProgress = true;
          }
          // 如果 suspended，这个令牌不再推进，等 resume()
        }
      }
    }

    // 检查流程是否完成
    state = this.checkProcessCompletion(state, definition);

    return state;
  }

  /**
   * 移动令牌到下一个节点
   */
  private async moveToNextNodes(
    state: ProcessState,
    token: Token,
    currentNode: Element,
    definition: ProcessDefinition
  ): Promise<ProcessState> {
    const outgoingFlows = currentNode.outgoing || [];

    // 销毁当前令牌
    state = this.tokenManager.destroyToken(state, token.id);

    // 为每条出边创建新令牌
    for (const flowId of outgoingFlows) {
      const flow = definition.sequenceFlows.get(flowId);
      if (!flow) continue;

      const targetNode = definition.elements.get(flow.targetRef);
      if (!targetNode) continue;

      // 触发 onSequenceFlow 钩子
      await this.hooks.emit('sequenceFlow', {
        state, token, flow,
        sourceNode: currentNode,
        targetNode,
        definition,
      });

      // 在目标节点创建新令牌
      state = this.tokenManager.createToken(state, flow.targetRef, token.data);
    }

    return state;
  }

  // ==================== 钩子注册 ====================

  on(event: string, handler: Function): void {
    this.hooks.register(event, handler);
  }

  off(event: string, handler: Function): void {
    this.hooks.unregister(event, handler);
  }

  // ==================== 查询 ====================

  getSuspendedTokens(state: ProcessState): SuspendedTokenInfo[] {
    return state.tokens
      .filter(t => t.status === 'suspended')
      .map(t => ({
        tokenId: t.id,
        nodeId: t.elementId,
        nodeType: t.nodeType || '',
        nodeName: t.nodeName || '',
        nodeProperties: t.nodeProperties || {},
        tokenData: t.data,
        suspendedAt: t.suspendedAt!,
      }));
  }

  // ==================== 插件 ====================

  use(plugin: FlowPlugin): void {
    plugin.install(this);
  }

  // ... 辅助方法
}
```

### 9.2 GatewayResolver.ts

```typescript
/**
 * 网关解析器
 * 引擎内部唯一保留的"节点执行逻辑"
 */
export class GatewayResolver {

  /**
   * 解析网关，返回新状态
   */
  resolve(
    state: ProcessState,
    token: Token,
    gateway: Element,
    definition: ProcessDefinition
  ): ProcessState {
    switch (gateway.type) {
      case 'bpmn:exclusiveGateway':
        return this.resolveExclusive(state, token, gateway, definition);
      case 'bpmn:parallelGateway':
        return this.resolveParallel(state, token, gateway, definition);
      case 'bpmn:inclusiveGateway':
        return this.resolveInclusive(state, token, gateway, definition);
      case 'bpmn:eventBasedGateway':
        return this.resolveEventBased(state, token, gateway, definition);
      default:
        return state;
    }
  }

  /**
   * 排他网关：评估条件，选择唯一分支
   */
  private resolveExclusive(
    state: ProcessState,
    token: Token,
    gateway: Element,
    definition: ProcessDefinition
  ): ProcessState {
    const outgoingFlows = gateway.outgoing || [];
    let selectedFlowId: string | null = null;
    let defaultFlowId = gateway.properties?.default || null;

    // 按顺序评估条件，选择第一个为 true 的
    for (const flowId of outgoingFlows) {
      if (flowId === defaultFlowId) continue;
      const flow = definition.sequenceFlows.get(flowId);
      if (!flow) continue;

      if (flow.conditionExpression) {
        const result = evaluateExpression(
          flow.conditionExpression,
          { ...state.data, ...state.variables, ...token.data }
        );
        if (result) {
          selectedFlowId = flowId;
          break;
        }
      } else {
        selectedFlowId = flowId;
        break;
      }
    }

    // fallback 到 default flow
    if (!selectedFlowId) selectedFlowId = defaultFlowId;
    if (!selectedFlowId && outgoingFlows.length === 1) {
      selectedFlowId = outgoingFlows[0];
    }

    // 销毁当前令牌，在选中的目标创建新令牌
    state = this.tokenManager.destroyToken(state, token.id);
    if (selectedFlowId) {
      const flow = definition.sequenceFlows.get(selectedFlowId);
      if (flow) {
        state = this.tokenManager.createToken(state, flow.targetRef, token.data);
      }
    }

    return state;
  }

  /**
   * 并行网关：分裂或汇聚
   */
  private resolveParallel(
    state: ProcessState,
    token: Token,
    gateway: Element,
    definition: ProcessDefinition
  ): ProcessState {
    const incoming = gateway.incoming || [];
    const outgoing = gateway.outgoing || [];

    if (incoming.length > 1) {
      // 汇聚模式：等待所有入边的令牌到达
      // 记录到达的令牌
      state = this.recordArrival(state, gateway.id, token.id);
      state = this.tokenManager.destroyToken(state, token.id);

      const arrivedCount = this.getArrivalCount(state, gateway.id);
      if (arrivedCount >= incoming.length) {
        // 全部到达，清除记录，向所有出边发令牌
        state = this.clearArrivals(state, gateway.id);
        for (const flowId of outgoing) {
          const flow = definition.sequenceFlows.get(flowId);
          if (flow) {
            state = this.tokenManager.createToken(state, flow.targetRef, token.data);
          }
        }
      }
      // 未全部到达：等待
    } else {
      // 分裂模式：向所有出边发令牌
      state = this.tokenManager.destroyToken(state, token.id);
      for (const flowId of outgoing) {
        const flow = definition.sequenceFlows.get(flowId);
        if (flow) {
          state = this.tokenManager.createToken(state, flow.targetRef, token.data);
        }
      }
    }

    return state;
  }

  // ... resolveInclusive, resolveEventBased 类似
}
```

## 十二、FAQ

### Q: 消息事件、信号事件、定时事件还需要实现吗？

**A**: 不需要在引擎里实现。外部应用在 `onNodeEnter` 钩子中识别这些事件类型，自己决定怎么处理：

```typescript
engine.on('nodeEnter', (ctx) => {
  if (ctx.node.type === 'bpmn:intermediateCatchEvent') {
    const eventDef = ctx.node.properties.eventDefinition;
    if (eventDef?.type === 'message') {
      ctx.suspend();
      messageQueue.subscribe(eventDef.messageRef, () => {
        engine.resume(state, ctx.token.id);
      });
    } else if (eventDef?.type === 'timer') {
      ctx.suspend();
      scheduler.scheduleAt(eventDef.timeDate, () => {
        engine.resume(state, ctx.token.id);
      });
    }
  }
});
```

### Q: 子流程怎么办？

**A**: 子流程节点在 `onNodeEnter` 中启动一个新的 FlowEngine 实例：

```typescript
engine.on('nodeEnter', (ctx) => {
  if (ctx.node.type === 'bpmn:subProcess') {
    ctx.suspend();
    const subEngine = new FlowEngine();
    // 复用同样的钩子...
    subEngine.on('processEnd', () => {
      engine.resume(state, ctx.token.id, subEngine.getResult());
    });
    subEngine.startProcess(ctx.node.properties.subProcessXML, ctx.token.data);
  }
});
```

### Q: 边界事件怎么办？

**A**: 边界事件作为节点的附加属性，外部应用在 `onNodeEnter` 时同时设置边界监听：

```typescript
engine.on('nodeEnter', (ctx) => {
  if (ctx.node.type === 'bpmn:userTask') {
    ctx.suspend();

    // 检查是否有边界定时事件
    const boundary = ctx.node.properties.boundaryEvents?.find(
      e => e.type === 'timer'
    );
    if (boundary) {
      const timer = setTimeout(() => {
        // 超时，走边界路线
        engine.resume(state, ctx.token.id, { timedOut: true });
      }, boundary.duration);

      // 正常完成时清除定时器
      onTaskComplete(() => clearTimeout(timer));
    }
  }
});
```

### Q: 和 bpmn-engine / Camunda 的区别？

**A**: 
- **Camunda**: 全功能引擎，实现所有 BPMN 规范，Java 生态，重量级
- **bpmn-engine**: Node.js 引擎，有自己的活动执行模型，中量级
- **bpmn-flash v3**: **纯流转控制器**，不实现任何业务逻辑，极轻量级

定位是嵌入式流程引擎，适合：
- 前端/Node.js 应用内嵌
- 需要完全自定义节点行为的场景
- 轻量级工作流（审批流、状态机）
